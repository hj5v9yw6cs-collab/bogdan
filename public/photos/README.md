# Фотографии

Положите сюда файлы с этими именами — сайт подхватит их автоматически:

| Файл | Что это | Где используется |
|---|---|---|
| `portrait-studio.jpg` | Ч/б студийный портрет в очках | About Me, Safari, About This Mac, Photos |
| `portrait-face.jpg` | Портрет анфас | Contacts, Resume, Mail, Photos |
| `portrait-boutique.jpg` | Портрет в бутике (чёрный пиджак) | Photos |
| `portrait-tuxedo.jpg` | Black tie, селфи в зеркале | Photos |

Остальные фото (города, работа) — добавьте файл и пропишите `src: '/photos/имя.jpg'`
у нужной записи в `src/data/content.ts` → `photos`.
Рекомендации: JPG, 1600–2400 px по длинной стороне, до ~500 KB.
